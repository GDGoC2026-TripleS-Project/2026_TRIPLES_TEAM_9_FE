# 2026_TRIPLES_TEAM_9_FE

대학 연합 프로젝트 TripleS FE 9팀 레파지토리입니다.

## 📌 프로젝트 소개

학습 기록 및 관리 웹 서비스 **지식정원**입니다.

## 🛠 기술 스택

| 분류       | 기술         |
| ---------- | ------------ |
| 프레임워크 | React        |
| 빌드 도구  | Vite         |
| 스타일링   | CSS          |
| 라우팅     | React Router |
| 아이콘     | lucide-react |

## 📁 폴더 구조

```bash
src
├─api

├─components

├─hooks
├─lib
├─pages
├─routes
├─services

```

## 📌 Commit Convention

| Type     | Description                  |
| -------- | ---------------------------- |
| feat     | 새로운 기능 추가             |
| fix      | 버그 수정                    |
| docs     | 문서 수정                    |
| style    | 코드 포맷팅 (기능 변경 없음) |
| refactor | 코드 리팩토링                |
| test     | 테스트 코드 작성             |
| chore    | 빌드 설정, 패키지 관리       |

### 🔖 커밋 예시

이슈 생성 후 커밋

```bash
git commit -m "#1 feat: 로그인 기능 구현"
```

## 🚀 실행 방법

```bash
# 패키지 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build
```
